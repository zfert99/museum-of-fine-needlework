# Museum of Fine Needlework

Nonogram puzzles presented as an earnest museum of cross-stitch. Each exhibit is a 10×10 stitched picture of something mundane, restored square by square, and the galleries descend from the kitchen drawer to somewhere much stranger.

Open `index.html` in a browser to play. No build step or server is needed.

- `PROJECT.md`: design notes, decisions, parked ideas, and how to add a work
- `tools/check-unique.js`: checks that each puzzle has exactly one solution (`node tools/check-unique.js`)
